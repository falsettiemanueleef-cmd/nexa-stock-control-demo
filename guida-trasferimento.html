NEXA STOCK CONTROL
GUIDA RAPIDA · TRASFERIMENTO DATI
4 PASSAGGI

Porta il tuo magazzino da un dispositivo all’altro.

Usa questa procedura quando vuoi passare dal PC al telefono o dal telefono al PC. Non serve un account cloud.

Usa il gestionale anche senza Internet.

La prima apertura e l'installazione richiedono una connessione. Dopo aver installato l'app e averla aperta almeno una volta online, le schermate principali vengono conservate sul dispositivo per l'uso offline. Quando viene pubblicato un aggiornamento, apri l'app con Internet attivo una volta per riceverlo; non è necessario reinstallarla.

A

Android

Apri il gestionale con Chrome. Tocca il menu ⋮ e scegli Installa app oppure Aggiungi a schermata Home, se disponibile. Avvia l'app una volta con Internet attivo.

B

Windows

Apri il gestionale con Edge o Chrome. Dal menu del browser scegli Installa app oppure Crea collegamento. Avvia l'app una volta con Internet attivo.

USO OFFLINE
Una volta caricata e installata correttamente, l'app può riaprire le schermate già memorizzate anche senza connessione. Le funzioni di gestione e salvataggio lavorano sul dispositivo. Ogni dispositivo conserva il proprio archivio locale: PC e telefono non si sincronizzano automaticamente. Continua a usare Esporta dati e Importa dati per trasferire gli aggiornamenti.
1

Esporta i dati

Apri NEXA STOCK CONTROL sul dispositivo dove hai gli ultimi aggiornamenti. Premi ESPORTA DATI. Verrà scaricato un file di backup con prodotti, giacenze e movimenti.

↓　FILE BACKUP
2

Trasferisci il file

Invia il file all’altro dispositivo usando un metodo a tua scelta: email, WhatsApp o Google Drive. Conserva il file originale finché non hai verificato il trasferimento.

⇢　PC / TELEFONO
3

Importa i dati

Apri NEXA STOCK CONTROL sull’altro dispositivo. Premi IMPORTA DATI e seleziona il file di backup appena ricevuto. Conferma solo se sei sicuro che sia il backup corretto.

↑　IMPORTA BACKUP
4

Controlla il risultato

Verifica alcuni prodotti, le quantità e gli ultimi movimenti. Da quel momento continua a lavorare sul dispositivo aggiornato. Per tornare sull’altro, ripeti i quattro passaggi.

✓　DATI TRASFERITI
ATTENZIONE — IMPORTANTE
L’importazione sostituisce i dati presenti sul dispositivo di destinazione. Prima di importare, esporta anche da quel dispositivo una copia di sicurezza, se contiene dati che vuoi conservare. Non lavorare contemporaneamente su PC e telefono: le modifiche non si uniscono da sole. Trasferisci sempre il backup più recente.
