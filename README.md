# NEXA STOCK CONTROL — Demo

Prototipo interattivo per la gestione di un piccolo magazzino.

## Funzioni dimostrative
- Dashboard con prodotti, pezzi disponibili, scorte sotto soglia e vendite.
- Ricerca e filtro dell'inventario.
- Registrazione di carichi e vendite, con blocco delle vendite oltre la giacenza.
- Suggerimento quantità da riordinare.
- Report e classifica dei prodotti venduti.
- Inserimento di nuovi prodotti.

## Avvertenza
Questa è esclusivamente una demo con dati fittizi. I dati e le modifiche sono mantenuti soltanto in memoria durante la sessione del browser e si azzerano al ricaricamento. Non inserire dati reali o riservati. Non è un gestionale pronto per l'uso aziendale.

## Avvio
Aprire `index.html` in un browser oppure pubblicare il repository con GitHub Pages (branch `main`, cartella `/(root)`).
